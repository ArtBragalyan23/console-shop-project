# console-shop-project
Мой маленький проект, консольного интерфейса управления магазином, с функционалом добавления, вывода, удаления, изменения пользователей, продуктов и заказов. Вся информация о заказах товарах и пользователях лежит на БД. Основной функционал сделан, не сделано еще много чего и в планах обновлять данный маленький проект.
На данный момент сделана база, в примитивном виде, в пакете models представлены основные классы (такие же сущности в БД PostgreSQL): Users для управления пользователями (добавление, удаление, изменение, обновление, поиск по ID, вывод всех пользователей), Product для управления товарами, Order для управления заказами и  OrderItem который содержит ID, ID
